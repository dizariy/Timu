# Источники цен и истории сырья

`GET /api/commodities` возвращает данные `server/commodity-data.mjs`. Начальный проверенный снимок находится в `dist/data/commodity-regions.json`. Снимок содержит реальные наблюдения; демонстрационные ряды и интерполяция отсутствуют.

## Что означает цена

| Набор | Тип данных | Единица | История |
| --- | --- | --- | --- |
| РФ, золото/серебро/платина/палладий | Официальная учётная цена Банка России | RUB за грамм | Опубликованные значения за последние 364 дня |
| РБ, те же четыре металла | Официальная учётная цена НБ РБ | BYN за грамм | Опубликованные значения за последние 364 дня |
| Мир, четыре драгметалла | Индикативная цена Gold API | USD за тройскую унцию | Gold API не предоставляет бесплатную историю без ключа |
| World Bank: медь, алюминий, никель, цинк | Мировая среднемесячная цена | USD за метрическую тонну | Последние 60 опубликованных месяцев |
| World Bank: Brent | Мировая среднемесячная цена | USD за баррель | Последние 60 опубликованных месяцев |
| World Bank: газ США | Мировая среднемесячная цена | USD за миллион БТЕ | Последние 60 опубликованных месяцев |

Учётная цена центрального банка — **не биржевая цена сделки, не банковская цена продажи слитка и не спред покупки/продажи**. Источник MOEX в этом модуле не подключён.

Для промышленного сырья значения RUB/BYN — произведение мировой средней цены за указанный месяц и последнего официального курса USD. Они помечены `kind: converted`; это **не местная биржевая котировка**. Дата месяца цены и дата валютного курса сохраняются отдельно. История в RUB/BYN для таких пересчётов оставлена пустой: умножение всей истории на сегодняшний курс не выдаётся за исторические локальные цены. Для графика доступен исходный ряд USD с его единицей.

## Официальная документация и проверенные запросы

- [Банк России: XML-сервисы](https://www.cbr.ru/development/SXML/) — `https://www.cbr.ru/scripts/xml_metall.asp?date_req1=DD/MM/YYYY&date_req2=DD/MM/YYYY`. XML в Windows-1251, дробная запятая. Коды 1–4: золото, серебро, платина, палладий. После 01.07.2008 поле даты обозначает действующую дату цены.
- [Банк России: методика учётных цен](https://www.cbr.ru/hd_base/metall/) — цены рассчитываются каждый рабочий день и действуют со следующего календарного дня до новых значений. Поле `Buy` современного XML используется как учётная цена; оно не означает доступное пользователю предложение купить металл.
- [НБ РБ: API цен металлов](https://www.nbrb.by/APIHelp/BankIngots) — `https://api.nbrb.by/metals` и `https://api.nbrb.by/bankingots/prices?startdate=YYYY-MM-DD&enddate=YYYY-MM-DD`. Максимальный диапазон — 365 дней. `MetalId` 0–3 соответствует золоту, серебру, платине и палладию; `Value` — цена на `Date`.
- [Банк России: валютные курсы](https://www.cbr.ru/development/SXML/) — `XML_daily.asp?date_req=DD/MM/YYYY`; USD извлекается по `CharCode` и делится на `Nominal`.
- [НБ РБ: API валютных курсов](https://www.nbrb.by/APIHelp/ExRates) — `https://api.nbrb.by/exrates/rates/USD?parammode=2&ondate=YYYY-MM-DD`; `Cur_OfficialRate / Cur_Scale` даёт BYN за 1 USD.
- [World Bank Commodity Markets](https://www.worldbank.org/en/research/commodity-markets) — официальный [ежемесячный XLSX](https://thedocs.worldbank.org/en/doc/74e8be41ceb20fa0da750cda2f6b9e4e-0050012026/related/CMO-Historical-Data-Monthly.xlsx), лист `Monthly Prices`. Значения номинальные, в USD. Первое число в `history.date` является технической меткой месяца, **не ценой на первый день месяца**. История золота, серебра и платины в мировой вкладке также берётся из месячного World Bank и явно помечается `historyFrequency: monthly`; палладия в этой таблице нет.
- [Gold API](https://gold-api.com/docs) — `/price/XAU`, `/price/XAG`, `/price/XPT`, `/price/XPD`, без ключа. Сохраняются исходные `updatedAt`, символ и валюта; дневное изменение отсутствует и не вычисляется из несопоставимых наблюдений. Физическая единица следует стандартной конвенции символов XAU/XAG/XPT/XPD; API отдельного поля `unit` не возвращает. [Условия](https://gold-api.com/terms) допускают использование в приложениях и запрещают частые запросы, создающие нагрузку.

Документация и реальные ответы проверены 07.10.2026. В первом успешном полном ответе: 247 точек CBR и 253 точки НБ РБ на каждый металл, по 60 месячных точек для девяти рядов World Bank. Последний месяц World Bank — сентябрь 2026; публикация обновлена 02.10.2026. Даты текущего снимка читаются из самого JSON и могут быть новее.

## Контракт и обновление

Ответ: `{ schemaVersion, updatedAt, status, items, fx, errors, sources, notes }`. `updatedAt` верхнего уровня — время получения ответа приложением, **не общая дата всех цен**. У каждого ряда есть `dataAsOf`, `updatedAt`, `frequency`, `source`, `history`, `regions.RU/BY`. Источник имеет `{ name, url, kind, method? }`. История — массив `{ date, price }` без заполнения выходных или пропусков.

Кэш полного ответа — до шести часов, с обновлением после смены московской даты. Это распространяется и на сохранённую индикативную цену Gold API: интерфейс показывает её исходное время. Ручной запрос `?force=1` обновляет раньше, когда с последней попытки прошла минута. Одновременные запросы объединяются. Запросы Gold API стартуют с интервалом 1,2 секунды параллельно с региональными источниками. Ответы ограничены таймаутами и размером. Прямые запросы к Gold API из браузера предусмотрены как резерв при недоступности серверных данных.

При ошибке сохраняются предыдущие реальные значения с исходной датой; общий ответ становится `partial`, причины находятся в `errors`. Региональный резервный ряд получает `status: cached`. Индикативная цена старше 15 минут по времени поставщика получает `stale`; этот порог не определяет, открыт ли рынок. Неверные цены, даты и неполные ряды не заменяются нулями.

## Проверка без сети

`node check-commodities.mjs` проверяет парсеры CBR/NBRB, дробные запятые, идентификаторы, неверные даты и типы, сортировку и дубликаты, повреждённый XLSX, реальные сохранённые ряды, единицы измерения, смысл FX-пересчёта и независимость возвращаемой копии кэша. Проверка не обращается к поставщикам.

## Где купить физические слитки

Раздел запрашивает `/api/commodity-offers` при открытии карточки. Число в строке — опубликованная цена продажи за целый слиток. Рядом указаны масса, проба, дата, условия и ссылка на поставщика. Каждый рынок показан в своей валюте.

- Беларусь. [Белагропромбанк](https://www.belapb.by/about/spravochnaya-informatsiya/vitriny/dragotsennye-metally/) и [Белгазпромбанк](https://belgazprombank.by/personal_banking/operacii_s_dragocennimi_metallami/tekuschie_ceni_kupli_prodazhi_mernih_sli/) публикуют цены на золото, серебро и платину. Для [МТБанка](https://www.mtbank.by/investments/slitki-dragocennyh-metallov/) цена золота показана справочно до подтверждения пробы.
- Россия. [Уралпромбанк](https://www.uralprombank.ru/person/dragotsennye-metally-i-monety/dragotsennye-metally-v-slitkakh/kursy-dragotsennykh-metallov) публикует цены золотых слитков без пробы в таблице. [Росвексель](https://www.rsvx.ru/) показывает цену физического слитка без доставки. Обе цены справочные.

Отметка наименьшей опубликованной цены появляется при наличии не менее двух поставщиков с одинаковыми массой и пробой. В расчёт входят цены с раскрытыми условиями, опубликованные сегодня или накануне, если сайту поставщика удалось ответить в последние 30 минут. Предложения с неполной суммой, неизвестной пробой, отсутствующей датой и сохранённые снимки остаются справочными. Проверка не подтверждает складской остаток.

Для промышленного сырья сопоставимых розничных предложений пока нет. Карточка указывает доступные площадки для оптового запроса и условия, которые нужно сверить, включая марку, партию, доставку и налоги. Цены учётных рядов и среднемесячные значения остаются в графике.
