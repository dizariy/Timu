## Дополнение: каталог, баннер и сырьё

- На мобильной ширине 393 px и настольной компоновке горизонтального переполнения нет.
- По DOM-отметкам между посадкой логотипа и показом фотографии прошло 2 007 мс. При перезапуске предыдущий фон hero.webp сменился на hero-4.webp; тёмный hero-3.webp получил светлый логотип, светлые фотографии — тёмный.
- Известные компании получили собственные градиенты: NVIDIA — зелёный, Microsoft — синий, Apple — серый, Meta — синий с исходным голубым знаком. Оранжевый timu проверен на записи без знака.
- Каталог: 5 857 записей, фильтры США/Мосбиржа, поиск SBER возвращает SBER и SBERP, открытие SBER показывает MOEX. Основной поиск «Газпром» возвращает GAZP.
- Полный каталог грузится после маленького core; его результат защищён от позднего ответа core. Ответ каталога не может перезаписать уже другое открытое окно.
- «Сырьё» реально получило новые ответы для всех пяти инструментов Gold API. При последующих частичных сетевых сбоях сохранённые значения остались на экране с датой и пометкой «нет связи». Повторный успешный ответ снимает пометку.
- Поиск «золото» оставил одну карточку; очистка вернула все инструменты. Фиксированная лупа доступна при прокрутке.
- Месячные ряды показывают период «сентябрь 2026», отделены от обновляемых цен и не выдаются за спотовые значения.
- Контраст проверяется вне обработчика прокрутки. Повторная заставка инвалидирует незавершённый расчёт цвета. Обновление сырья сохраняет клавиатурный фокус на ссылках источников.
- Сохранены актуальные мобильные снимки home и commodities. Ошибок JavaScript при проверке нового интерфейса не обнаружено.

Ограничения: проверка не является измерением FPS на реальном телефоне. Нет проверки Safari/iOS и непрерывного API акций. История акций остаётся демонстрационной до импорта CSV, прогнозной модели нет. Gold API может временно не отвечать; месяц World Bank обновляется отдельным снимком. Публикация в Sites ранее остановлена политикой разрешений на шаге передачи данных в workflow; локальная версия работает.
