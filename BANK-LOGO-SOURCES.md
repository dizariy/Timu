# Логотипы банков

Графические знаки взяты из [публичной выдачи курсов Myfin](https://myfin.by/currency/minsk) по названиям банков. Права на знаки принадлежат их владельцам. В приложении они служат для идентификации банков.

Приложение использует локальные копии. SVG очищены от сценариев и внешних ссылок. Для банка без знака показываются инициалы.
