# Наличные курсы Беларуси

Проверено 18 ноября 2026. Новый раздел «Валюта» получает USD/BYN и EUR/BYN через локальный `/api/currency`. Значения означают BYN за одну единицу валюты. Покупка — банк покупает валюту у пользователя; продажа — банк продаёт её пользователю. Лучшее предложение определяется максимумом покупки и минимумом продажи отдельно для каждой валюты.

## Источники и охват

- Myfin: публичные таблицы отделений Минска, Бреста, Витебска, Гомеля, Гродно и Могилёва (`https://myfin.by/currency/<город>`). Берутся строки отделений с адресом, курсами и временем обновления. Рекламные и отдельные онлайн-предложения не смешиваются с наличным обменом.
- Беларусбанк: официальный `https://belarusbank.by/api/kursExchange`, отделения по стране. Поля `USD_in`/`EUR_in` — покупка банком, `USD_out`/`EUR_out` — продажа. Нули означают отсутствие предложения. Время берётся из `kurs_date_time`.
- При успешном ответе официального API его отделения заменяют записи Беларусбанка из Myfin, чтобы не дублировать их.

При проверке получено 1 776 предложений отделений 22 банков и обменных сетей. Это охват подключённых источников, а не подтверждённый полный реестр всех обменников Беларуси. В интерфейсе эта граница указана возле курсов. Если часть источников недоступна, отображаются частичное обновление и фактически полученные города.

## Даты и обновление

Фоновая проверка источников выполняется раз в пять минут, пока раздел открыт и вкладка видима. Ручная проверка может обновить данные раньше, если с последней попытки прошла минута. Одновременные запросы объединяются. Дата проверки сервера не заменяет дату курса: для Myfin используется явно указанная дата страницы и время строки; для Беларусбанка — дата и время API. Часовой пояс источников — Минск, UTC+3. Неизвестное время показывается как неизвестное.

При сбое остаётся последний снимок с пометкой сохранённых данных. Пустой ответ не заменяет последнюю успешную подборку. Лучшие курсы вычисляются среди доступных предложений и с учётом поиска по банку или городу. В списке «Все банки» каждый банк показан один раз; для каждой стороны обмена указан адрес отделения и время выбранного курса. Курсы в других отделениях могут отличаться.

## Ограничения

Курс не гарантирует наличие наличной валюты, открытое отделение, доступность операции или отсутствие дополнительных условий. Ссылка у банка или адреса ведёт к источнику предложения. Система не выполняет финансовые операции. Расширение до полного покрытия всех городов и независимых обменников требует отдельного полного источника данных.

## Оценка следующего изменения

Сервер получает примерно три месяца дневных официальных курсов USD и EUR через [API НБРБ](https://api.nbrb.by/exrates/rates?periodicity=0). В расчёт входят данные по текущую дату Минска. Последовательные повторы одного значения объединяются. Оценка на одну следующую публикацию с изменением равна медиане последних семи изменений. Типичная ошибка — медиана абсолютных ошибок при последовательной проверке на прошлых данных. Когда оценка меньше типичной ошибки по модулю, сигнал помечается слабым. Если свежего ряда или наблюдений недостаточно, оценка скрывается.

Стрелки рядом с обеими банковскими котировками относятся к одному официальному курсу валюты. Спред, комиссии и цены отдельных отделений в модель не входят. Знаки банков описаны в BANK-LOGO-SOURCES.md.
