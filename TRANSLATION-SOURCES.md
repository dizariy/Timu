# Перевод новостей

Используется документированный GET https://api.mymemory.translated.net/get с q, langpair=en|ru, mt=1. Ключ, адрес электронной почты и пользовательские сведения не отправляются. Операции публикации переводов set и импорта памяти переводов не вызываются.

Официальные страницы получены и прочитаны 8 октября 2026:

- [Спецификация MyMemory](https://mymemory.translated.net/doc/spec.php): максимум 500 байт UTF-8 в сегменте, машинный перевод через mt=1.
- [Лимиты MyMemory](https://mymemory.translated.net/doc/usagelimits.php): анонимный режим 5 000 символов в день; повышенные квоты не подключены.

server/news-translation.mjs применяет собственный предел 4 800 символов за день UTC, разбивает длинные поля по границам слов, объединяет одинаковые параллельные запросы и сохраняет результат по содержимому исходного текста. Фактическая квота поставщика остаётся решающей. При лимите, таймауте или некорректном ответе возвращается неизменённый оригинал. Повторные неудачные запросы подавляются на минуту. Таймаут сегмента — десять секунд.

Маршрут /api/news/translation?id=... принимает только идентификатор уже имеющейся серверной публикации. Произвольный текст и внешние URL не принимаются. Результат вставляется через textContent или HTML-экранирование, не как исполняемая разметка.

Перевод запрашивается при открытии англоязычной новости. Доступны оригинал и первоисточник. Результат также используется в её карточке. Это перевод короткого анонса, не всей внешней статьи. Машинный перевод не гарантирует точности всех финансовых формулировок.

Проверен реальный ответ для публикации SMJ International Holdings Inc. о предупреждении NYSE American LLC: русский заголовок и анонс, HTTP 200, translated: true. check-translations.mjs проверяет без сети кэш, параллельные запросы, квоту, возврат и сохранение оригинала, ограничения UTF-8.
